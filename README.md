# Claudim — Sistema para Distribuidora de Bebidas

Sistema de gestão para distribuidoras de bebidas: cadastro de produtos, controle
de estoque, vendas/pedidos, faturamento, logística de entregas, financeiro e
relatórios gerenciais.

Este repositório contém, nesta fase, a **documentação** e o **plano de trabalho**
do projeto. A implementação será feita de forma incremental, conforme o roadmap
descrito em [`docs/05-plano-de-trabalho.md`](docs/05-plano-de-trabalho.md).
